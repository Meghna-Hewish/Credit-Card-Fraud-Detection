# Credit Card Fraud Detection

This project uses machine learning algorithms to detect fraudulent credit card transactions.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn

## Features
- Data preprocessing and cleaning
- Feature selection
- Model training and evaluation
- Fraud detection prediction

## Project Objective
To build a classification model that can accurately identify fraudulent transactions and reduce financial risk.

## Future Improvements
- Deploy model using Flask
- Improve accuracy with advanced models
